A controlled route into desktop geoscience

The public MCP server exposes 41 tools without depending on the Ocean SDK. Its documented toolbox includes 32 tools that work on project or export files without launching Petrel. Other routes call saved Petrel workflows or use bounded GUI procedures when required.

The engineering aim is to make each operation inspectable: explicit inputs, validation artifacts, checksums and a result audit. Tools that can launch Petrel default to dry runs and require explicit execution. Unresolved layouts or failed preflights return their limits instead of guessing.

Version and workflow support

The toolbox was developed and tested for Petrel 2018.2. It combines direct file processing, saved Petrel workflows and selected GUI procedures. Application-based routes need project-specific setup.

Supported examples include project inventories, surface and seismic exports, and Well Tops ASCII workflows. Native marker-pick decoding and creation of arbitrary new Workflow Editor commands remain outside the current toolset.

What this demonstrates

This project connects geoscience software knowledge with agent-tool design: file-based operations first, saved native workflows where supported, bounded UI steps when necessary, and clear checks and error reporting.
