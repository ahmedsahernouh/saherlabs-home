Understanding a project portfolio

Before reusing a collection of Petrel projects, a reviewer needs to know what each project contains and which information is accessible. This workflow brings project and companion metadata into one inventory without launching Petrel.

The report combines registry and Model metadata, identifies stored CRS declarations, and distinguishes readable information from missing, unsupported or unprobed items.

Results and interpretation

Of 98 selected project entries, 81 provided both Registry and Model metadata, four provided Registry metadata only, and 13 had neither available for the inventory.

These counts describe metadata coverage. Dataset extraction and coordinate validation are separate tasks: a stored CRS declaration or seismic reference alone does not confirm usable coordinates or a readable seismic volume.
